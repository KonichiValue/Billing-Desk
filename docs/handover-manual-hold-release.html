手動ホールドの一括解除について

東京ガス株式会社 ご担当者様｜Kraken Technologies Japan

1. ご相談の内容

手動で付与されたホールドの一括解除は、現在Krakenで実施しております。この作業を 東京ガス様ご自身で実施いただけるよう、権限をお渡ししたいと考えております。

現在は、対象アカウントのCSVとホールド理由をSlackでいただき、Krakenがジョブを実行して 完了をご報告する流れです。対象の一覧はすでに東京ガス様側でご用意いただいておりますので、 権限をお渡しできれば、実行のタイミングまで東京ガス様側で決められるようになります。

先にお伝えしたいこと

この作業は、別途ご相談しております「請求の強制発行」「請求書の強制印刷」と同じ 権限で実施できます。ご担当者と権限範囲のご判断は、3件をまとめてご検討いただけます。

2. 対象になるホールド

本資料の対象手動で付与されたホールドの一括解除です。ホールド理由を 指定して、まとめて解除します。
対象外システムが自動で付与したホールドの解除は、「請求の強制発行」の 作業に含まれます。別チケットでご相談しております。

3. 作業の流れ

  1. 対象アカウントのCSVをご用意ください。1列のみで、1行目に account_number というヘッダーが必要です。ホールド一覧から CSVで出力することもできます。
    Billing → Billing Dashboard → New Issuance → 該当のホールド理由
  2. 手動ホールドの管理画面を開きます。
    https://support.tokyogas-kraken.energy/billing/manage-manual-holds/
  3. Tasks の Invalidate manual holds in bulk を開きます。
  4. CSVファイルをアップロードし、解除するホールド理由を選択して Invalidate Holds を実行します。
  5. Billing Dashboard の New Issuance で、解除したホールドが一覧から消えていることを ご確認ください。実行画面には成功の表示のみが出て、アカウント単位の結果は表示されません ので、確認はこの画面で行っていただく形になります。

解除しただけでは、請求書のホールドはその場では外れません

解除の反映は、日次の請求処理の中で行われます。実行した時点では、すでにホールドが 付いている請求書のホールドは残っておりますので、翌日の処理をお待ちいただく形になります。 それより早く外す必要が生じた場合は、Krakenまでお知らせください。

4. 権限と役割分担

必要な権限現在の設定では BILLING_EXPERT 権限で実施できます。 強制発行・強制印刷と同じ権限ですので、1回の付与で3件とも可能になります。
東京ガス様対象アカウントとホールド理由のご判断、作業の実施、 ホールド一覧での結果確認。
Kraken権限の付与と管理、エラーが出た場合の原因調査。

この権限では、手動ホールドの解除だけでなく、付与も可能になります。システム上、解除のみに 絞ることはできません。範囲を絞る場合はシステム側での対応が必要となりますので、実現の可否と 時期は、あらためてご連絡いたします。

5. よくあるご質問

Q. すでに解除済みのアカウントが含まれていても問題ありませんか。
問題ございません。指定した理由のホールドが付いていないアカウントは、エラーにならず そのままスキップされます。前回の依頼分と重複していても、そのままご実行いただけます。
Q. 同じ請求書に複数のホールドが付いている場合はどうなりますか。
指定したホールド理由のホールドのみが解除されます。別の理由のホールドは残りますので、 その請求書は引き続き発行されません。
Q. どのアカウントが解除されたかは分かりますか。
実行画面ではアカウント単位の結果は表示されず、成功の表示のみとなります。結果は ホールド一覧の画面でご確認ください。
Q. エラーになる場合、何を確認すればよいですか。
CSVファイルに余分な文字や書式が含まれていると、エラーになることがございます。 過去のご依頼でも数回発生しておりますので、まずファイルの中身をご確認ください。解決しない 場合はKrakenまでお知らせください。
Q. 解除すると請求書は発行されますか。
解除だけでは発行されません。ホールドが外れたあと、通常の請求処理の中で発行されます。 すぐに発行が必要な場合は、強制発行の作業をご検討ください。
Q. 権限は誰に付与されますか。
ご指名いただいた方のみに付与いたします。人数や交代の運用は、東京ガス様側で 決めていただいて構いません。

6. 今後の進め方

  1. ご担当者を決めていただく。
  2. 権限の範囲について、BILLING_EXPERT で問題ないかをご判断いただく。強制発行・ 強制印刷のご判断と合わせてご検討いただけます。
  3. Krakenで権限を付与し、付与状況をご報告する。
  4. 操作説明の場を設ける。他の2件と同じ場でまとめて実施することも可能です。

ご不明な点は、Billingスタンドアップまたは該当チケットにてお知らせください。
